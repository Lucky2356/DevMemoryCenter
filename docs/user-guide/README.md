# User Guide Status

The application is not yet an MVP. The current shell provides localized navigation and clearly labelled availability states, but it has no data collection, project management, terminal import, search, sessions, timeline storage, export, or deletion behavior.

The navigation can be used with the keyboard, begins with a “Skip to main content” link, and identifies the current section. Terminal Memory remains explicitly disabled until its privacy and redaction controls are implemented. User guidance will be expanded with each real feature and must continue to explain privacy, error recovery, and deletion scope.
